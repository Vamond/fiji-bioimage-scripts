# FIJI BioImage Scripts

A collection of FIJI macros for biomedical image analysis.

## Introduction

This project contains a collection of FIJI macros for common image analysis tasks in biomedical research. These scripts aim to simplify and standardize the analysis workflow of experimental images and improve work efficiency.

## Categories

### Western Blot Analysis
- Band intensity analysis
- Multiple lane analysis

### Histology Analysis
- DAB staining quantification
- H&E staining analysis
- Tissue area measurement

### Fluorescence Analysis
- Colocalization analysis
- Intensity profile analysis
- Particle counting

### Wound Healing Analysis
- Scratch area measurement
- Cell migration tracking

### Utilities
- Batch processing
- Image preprocessing
- Results export

## Installation

1. Download scripts
   ```bash
   git clone https://github.com/vamond/fiji-bioimage-scripts.git
   ```

2. Copy desired scripts to FIJI macros directory
   - Windows: `%APPDATA%/Fiji.app/macros/`
   - MacOS: `/Applications/Fiji.app/macros/`
   - Linux: `~/Fiji.app/macros/`

3. Restart FIJI
